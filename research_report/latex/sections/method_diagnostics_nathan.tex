\subsection{Direct-Output Marker Diagnostics}
\label{sec:earlier-diagnostic-method}

The Direct-output diagnostics examine marker frequency, decoding behaviour,
accent association, input modality and source wording. They use the frozen
outputs or explicitly selected re-run samples; the official predictions remain
unchanged.

\subsubsection{Decoding checks}
The initial audit examined the exact string \unk{} in the frozen Direct outputs,
its frequency by accent and repeated sentence, runtime/generation flags, and the
pinned tokenizer's encoding of Chinese references. Reference-tokenizer
co-occurrence is descriptive and does not identify which token the model
generated. Five originally affected clips per accent were therefore selected
using seed 760, giving 35 clips. The same Direct checkpoint was rerun while
retaining generated token IDs. This sensitivity experiment used CPU FP32,
PyTorch/torchaudio 2.8.0 and Transformers 4.57.6, rather than the full run's
GPU FP16 environment.

The comparison covered greedy decoding, greedy decoding with special UNK ID~1
suppressed, beam search with five beams, and beam search with that ID suppressed. Sampling
remained disabled and the 256-new-token limit was retained. A second check on
the same selected clips blocked the ordinary token sequences that spelled the
visible marker, using \texttt{bad\_words\_ids}. Each experiment checked baseline
agreement with the archived translations, counted literal markers and special
UNK IDs separately, and scored the same subset using SacreBLEU 2.6.0. Changed
outputs were inspected for alternative marker spellings. These post-hoc
experiments are evaluated on their selected samples, separately from the
official 4,200 predictions.
