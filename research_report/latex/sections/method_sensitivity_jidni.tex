\subsection{Subset and Speaker Sensitivity Checks}
\label{sec:sensitivity-method}

These checks ask whether the system comparison of Section~\ref{sec:statistics} changes when visibly marked outputs are removed, clips are split by recognition error, or each speaker is counted once. The archived predictions stay unchanged throughout. None of the checks is a validated remedy.

\subsubsection{Common marker-free subset}
The 3,692 clips whose archived Direct output contains no literal \unk{} (exact string, Section~\ref{sec:earlier-diagnostic-method}) form one subset for all systems, because no cascade output contains the string. Outputs that carry hidden special ID 1 stay in the subset (Section~\ref{sec:further-diagnostic-results}). On this subset the corpus metrics of Section~\ref{sec:metrics} and the paired gaps $\Delta_{s,s'}$ and $\Delta_{a;s,s'}$ are recomputed with the speaker-clustered bootstrap of Section~\ref{sec:statistics} ($B=1{,}000$, seed 760, 1,443 speakers). A verification check confirmed that this bootstrap reproduces Table~\ref{tab:paired-gaps} on the full set to four decimals. Marked and unmarked clips contain different sentences, so a difference between subset and full-set scores describes the clips that were removed.

\subsubsection{WER subsets}
Clips are split by normalized Whisper WER into 2,952 with $\mathrm{WER}=0$ (1,259 speakers) and 1,248 with $\mathrm{WER}>0$ (646 speakers). The paired gaps within each subset are estimated with the same bootstrap. WER is an output of the cascade's own first stage, so this split is descriptive.

\subsubsection{One clip per speaker}
One clip is drawn at random from each of the 1,586 speakers (seed 760). The draw removes within-speaker dependence. It also leaves the sample accent-imbalanced, with 41 to 527 clips per group. Intervals come from an ordinary bootstrap over clips ($B=1{,}000$, seed 760).

\subsubsection{Fallback rule}
In a post-hoc check, the archived Cascade-3.3B translation replaces the Direct output on the 508 marked clips, and the corpus scores are recomputed. No held-out validation was run.

\subsubsection{Worst clips}
For each system and accent group, the audit lists the ten clips with the lowest sentence chrF++, with the source sentence, the Whisper transcript, every output and the reference. The audit records how many of these clips score exactly zero and how many carry the marker, with the mean WER of the set.
